Your photos, edits, albums and ratings now sync between your devices through a computer you control. A few steps and you are ready.

Open the admin page Read the guides

What to do next

  1. 1

    Create your administrator

    Open the admin page and enter the one-time setup code the server printed when it started: run docker compose logs lightcraft, or look in the terminal running lightcraft-server serve.

  2. 2

    Add the people who use it

    On the admin page choose Users ▸ Add user. Each person gets a library of their own.

  3. 3

    Add photo folders optional

    Photos already on this machine, such as a NAS share, can become part of a library in place: Users ▸ the user ▸ Library folders.

  4. 4

    Connect your devices

    In LightBites open Settings ▸ Sync, type this server's address with a user name and password, then Sign In.

  5. 5

    Put HTTPS in front of it

    Phones and browsers away from home need an encrypted address. The guides show a Caddy setup with your own domain, and Tailscale as the easy alternative.
