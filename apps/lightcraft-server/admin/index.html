Connect a device

Sync a library with this server from LightCraft on a Mac, PC or iPhone.

  1. In LightCraft, open Settings › Sync.
  2. Enter the server address above.
  3. Sign in with a user name and password from Users.

Or open the server address in a web browser to use LightCraft there.

Server details

Set when the server starts

The data folder, address and domain come from the deployment: --data / LIGHTCRAFT_DATA, --listen / LIGHTCRAFT_LISTEN, and your reverse proxy (LIGHTCRAFT_DOMAIN). Change them there and restart; moving a library under a running server can lose it.
