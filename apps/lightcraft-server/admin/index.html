LightCraft Server

Set up this server

Create the first admin. The setup code is in the server's log (docker compose logs lightcraft, or the terminal running lightcraft-server serve).

Sign in

Admins manage users, devices and storage here.

Server

Where the data lives, the address the server listens on and its domain are deployment settings: --data / LIGHTCRAFT_DATA, --listen / LIGHTCRAFT_LISTEN, and the domain in your reverse proxy (LIGHTCRAFT_DOMAIN with the compose file). Change them there and restart; moving a library under a running server can lose it.
