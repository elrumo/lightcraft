# Català

Catalan (`ca`, native name **Català**) is selected in **Edit → Language → Català** or **Settings →
General → Language**. The change applies at once and is saved for the next launch. The command is
`app.language.catalan`; the control channel accepts `ui.set {"language":"ca"}` and the tags `ca-ES`,
`ca_ES.UTF-8`. For headless runs set `LIGHTCRAFT_LANGUAGE=ca`.

The catalogs `crates/ui-egui/locales/ca.json` and `ca-formats.json` (egui) and
`apps/lightcraft-ios-swift/locales/ca.json` (the SwiftUI app's own wording; its
`Localizable.strings` is generated by `cargo xtask swift-strings`) were machine-translated with
Claude, by whole phrases from the English source, with the Spanish catalog as a meaning hint. No
native speaker or professional translator has reviewed them yet.

## Conventions

- Standard (IEC) Catalan; commands use the second-person singular imperative (Desa, Obre, Exporta…).
- Library = Biblioteca, Develop = Revelat, Album = Àlbum, Preset = Predefinit, Mask = Màscara.
- Highlights = Llums altes, Shadows = Ombres, Whites = Blancs, Blacks = Negres, Clarity = Claredat,
  Dehaze = Eliminació de boirina, Vibrance = Vibració, Saturation = Saturació.
- Thousands are grouped with a dot (41.721), as in Spanish and Italian.
- Counts use neutral wording; the English plural suffix argument is consumed with `{:.0}` like the
  other languages. Inter covers every Catalan letter (à, è, é, í, ï, ò, ó, ú, ü, ç, l·l); no extra font.
